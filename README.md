# Учебная платформа: ИСРПО Лабораторная работа №1

Образовательное веб-приложение для изучения лекций, прохождения тестирования и интерактивных заданий по дисциплине «Инструментальные средства разработки программного обеспечения».

## Возможности платформы
- Модуль лекций: каталог тем, фильтрация, поиск, поддержка HTML/видео/документов, учет посещения и реального времени нахождения на странице.
- Модуль тестирования: пул из 20 вопросов, случайная выборка 10 вопросов без повторов, рандомизация 4 вариантов ответа, таймер 10 минут, шкала оценивания (90% отлично, 75% хорошо, 60% удовлетворительно, менее 60% неудовлетворительно) с разбором ошибок.
- Интерактивный модуль: 3 типа заданий (Drag-and-Drop упорядочивание этапов SDLC/CI-CD, Drag-and-Drop группировка паттернов GoF, проверка регулярных выражений SemVer) с системой подсказок и подробным анализом ошибок.
- Ролевая модель: профили Студента и Преподавателя с быстрым переключением в интерфейсе.
- Минималистичный дизайн: бежево-черно-белая палитра, круглые кнопки, кастомные селекты и элементы форм, переназначенный скроллбар под акцентный цвет.

## Быстрый запуск

### Запуск одной командой через npm:
```bash
npm run dev
```
Сервер бэкенда и фронтенд автоматически поднимутся на http://localhost:8000

### Запуск тестов:
```bash
npm test
```

## Структура проекта
- `backend/` — серверный код на Python 3.12 (FastAPI, SQLite, Pytest)
- `frontend/` — клиентский SPA интерфейс (HTML5, нативный CSS3, Vanilla JS)
- `database/` — схема `schema.sql`, начальные данные `seed.sql`, ERD и архитектурные диаграммы
- `docs/` — отчеты по лабораторной работе (Markdown, Typst, скомпилированный PDF, макеты `LabWork1.drawio`)
- `run.js` — скрипт одновременного запуска бэкенда и фронтенда без сторонних утилит
- `package.json` — конфигурация запуска `npm start` и `npm run dev`
